# CMEHA website — client review version

A static, six-page website for the Cambodian Muslim Education and Humanitarian Association (CMEHA), prepared by BizWeb KH for CMEHA's design and content review.

- Pages: Home, About CMEHA, Programs & Projects, News & Events, Gallery, Contact (and Photo credits). English and Khmer.
- This is **not** the official CMEHA website. Content is subject to CMEHA approval; the four focus areas are not confirmed programs.
- Photographs are licensed stock images (credited on the Photo credits page); they are not photographs of CMEHA.
- The site is plain HTML, CSS and JavaScript. It makes no requests to any server, database or CMS and needs no build step: open `index.html` or serve the folder as static files. All paths are relative, so it works under a GitHub Pages repository sub-path.
- The pages ask search engines not to index them (`noindex, nofollow`). A public link can still be opened by anyone who has it: this is not access control.
- The Contact form only prepares an email in the visitor's own email app (info@cmeha-cambodia.org); nothing is sent or stored by the site.
